# 来源读取与恢复

读取已安装的 `~/.agents/skills/ego-browser/SKILL.md`，使用 `ego-browser nodejs`，必要时用 `~/.local/bin/ego-browser`。一次运行只建一个唯一命名 TaskSpace，记录 numeric spaceId 到本轮 browser.json，跨调用复用。上一次已 finish 的空间不能复用。Ego nodejs 的工作目录不一定是项目目录，保存文件必须用绝对路径。

主表初次载入可能先显示带 href 的工作表链接，再切换到 canvas。先快照，由当前 DOM 收集链接/role=tab 名称，保留当前清单。页脚可能横向滚动，不把视口内标签当作全部工作表。切换后等待目标 URL 和加载完成再截图；click 返回不代表内容已切换，旧 ref 可能过期。

当前文档可能禁用下载、导出、复制和副本。禁用时不调用导出接口，读取允许查看的内容并记录覆盖范围。

已见可用交互（未来使用前重新验证）：名称框 `input.bar-label` 可填写单元格地址，按 Enter 定位；公式栏 `.formula-input` 显示选中单元格完整文字。只改名称框选择位置，不向公式栏或表格输入内容。确认返回的实际地址：隐藏列/合并单元格可能使请求与实际地址不同。过去红包页可见列从 J 起，不应无限滚动找 A 列。

以下示例仅在当前 DOM 支持时使用：

```javascript
await page.fill('input.bar-label', address);
await page.press('input.bar-label', 'Enter');
const value = await page.evaluate(() => ({
  cell: document.querySelector('input.bar-label')?.value,
  text: document.querySelector('.formula-input')?.innerText
}));
```

先读标题、规则和日期，再筛选行。小批量读取可见单元格，截图辅助，按目的地定向定位；无需每次复制整个大型表格。新活动位置不固定，旧单元格为空不证明没有更新。链接从实际页面链接/可见提示提取，不编造地址。

日期单元格的显示格式可能隐藏年份：应查看该格公式栏原始值。例如一次实际读取中，红包页显示“10月8日”“11月30日”，原始值分别为 `2026/10/8`、`2026/11/30`。这能核实该行年份，但不能把核销/有效日期改成购买截止，也不能外推到另一工作表的年份。

默认“最新消息”是本轮主表、关联公告、活动页及身份已核实的公开作者更新。没有微信工具或用户新公告时，明确没有获取群内新增消息，不宣称追踪微信群。正文日期优先于标题；读取时间不是发布时间，源更新时间不明记 null。

官方规则/销售页验证期限和资格；博主私人返现仍需具体结算条件。网页唤起 App、登录、验证码按 Ego 交接，不使用系统快捷键或其他可见浏览器。无法到达销售页时降为候选或待核实，继续独立的公开规则研究。

无候选时可搜索当前月份+集团+闪促或原作者公开公告，检查正文年份及活动身份；搜索摘要只用于发现。其他渠道项目不得套用小菜鸡佣金或抽奖规则。历史约3%返现、100美元额度仅为待复核线索。

失败或用户接管时保存进度和空间 ID，可完成 coverage=partial 的结果，但不以旧缓存补齐当前项目。成功 finish({keep:[]})；需要用户继续操作时 handOff，不提前 finish。
